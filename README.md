# Ana Carolina · Revendedora Boticário

Catálogo online com pedido pelo WhatsApp. Site estático publicado pelo Netlify.

- `index.html` — página da loja (WhatsApp configurado no topo do script)
- `produtos.js` — catálogo do ciclo: preço cheio, desconto do ciclo e preço da Ana Carolina (compra + 5%, mínimo R$ 5)
- `s/` — fotos dos produtos em folhas de 10×10
